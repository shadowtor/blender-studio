# Code of conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), adapted below. It applies in issues, pull requests, discussions and any other space where the project is represented.

## Expected

- Be kind and assume good faith.
- Give and accept feedback on the work, not the person.
- Say plainly when you do not know something.

## Not accepted

- Harassment, insults, or discriminatory language.
- Sharing someone's private information.
- Spam or repeated off-topic posts.

## Enforcement

Report a problem by opening a private security advisory titled "Conduct report" (Security tab, then **Report a vulnerability**), or by contacting the maintainer, [@shadowtor](https://github.com/shadowtor), through GitHub. Reports are read by the maintainer only and handled privately. Responses can include a warning, deleting comments, or blocking a user from the repository.
