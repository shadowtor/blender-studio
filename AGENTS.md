# blender-studio

This repository is an Agent Skill for building 3D products, mockups and animations in Blender through the MCP for Blender add-on.

If you are an AI agent asked to make or render something in Blender, read `skills/blender-studio/SKILL.md` first and follow it. Its scripts are in `skills/blender-studio/scripts/`, its references in `skills/blender-studio/references/`. To install it for an agent, follow `docs/INSTALL-FOR-AGENTS.md`.

Working on the repository itself: run `python tools/smoke_test.py` before finishing, keep `SKILL.md` short, and mark anything you did not run in Blender as untested.
